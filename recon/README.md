# recon —— 逆向过程存档

这些脚本是逆向 HECATE G3M PRO 私有 HID 协议时用过的探针，**不是成品的一部分**，
留在这里只为复现与参考。

| 脚本 | 用途 |
|---|---|
| `hid_enum.py` | 用 SetupAPI 枚举 HID 设备，打印 VID/PID/产品名/报告描述符 |
| `hid_desc.py` | 同上，但会解析报告描述符，并读 `HidP_GetCaps` 的 in/out/feature 字节数（用它确认了 COL04 是 64→64） |
| `hid_probe.py` | 打开厂商集合（COL04）被动读取 64 字节输入报告 —— 关键一步：HID 输入报告会广播给所有读句柄，因此能在不 hook 进程的前提下看到官方软件与设备的真实往来 |
| `try_frames.py` | 早期试探：发送若干候选帧观察回包，用于确认帧结构 |
| `probe2.py` | 早期对照实验：变化请求字节，判断响应是回显还是设备数据 |

注意事项：

- 这些脚本里写死了本次实验的设备实例路径（如 `hid#vid_320f&pid_706e&mi_01&col04#9&101432e6&0&0003`），
  换了 USB 口或机器大概率失效，需要按 `hid_desc.py` 打印的实际路径替换。
- 都是 PowerShell/Python 标准库实现，不依赖 hidapi。
- 发送任意帧属于**写设备**操作，可能改变鼠标设置，仅在明确知道后果时使用。
